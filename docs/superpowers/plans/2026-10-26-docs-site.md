# Documentation site plan

**Spec:** `docs/superpowers/specs/2026-10-26-docs-site-design.md`
Intent-Issue: #35 — https://github.com/the9klabs/design/issues/35

**Goal:** turn the single-page showcase into a multi-page documentation site with a page per
component, foundations and guides, search, and a Markdown twin of every page.

## Tasks

1. **Dependencies.** Add `vitepress` and `@vue/compiler-dom` as dev dependencies; they serve the
   docs only and never reach `dist/`. Point `showcase` and `build:showcase` at VitePress.
2. **Catalog.** `showcase/site/catalog.ts` loads the registry through Vite, merges it with the API
   extracted from source, and lists every page (home, guides, components index, one per component)
   with its path, title, description and sidebar group. `slugFor('I9kNinoMaze')` is `nino-maze`.
3. **Config.** `showcase/.vitepress/config.ts` builds the nav and sidebar from the catalog, turns
   on local search and the outline, adds the canonical and Markdown-alternate links to each head,
   wires ` ```vue demo ` fences, and writes the machine files and sitemap in `buildEnd`.
4. **Theme.** Extend the default theme: map `--vp-*` onto the 9k tokens, import the library's
   stylesheet, and add `DocsDemo`, `DocsPageActions`, `DocsDirectionToggle`, `DocsHeroNino`,
   `DocsColorTokens`, `DocsRules` and `DocsComponentGrid`.
5. **Component pages.** `pages/components/[slug].paths.ts` generates each page from its registry
   entry: lede, page actions, import, demos above their code, gotchas, API tables, types, and the
   agent prompt.
6. **Twins and llms files.** `showcase/site/markdown.ts` and `twins.ts` write a twin per page,
   `llms.txt`, `llms-full.txt`; `components.json` stays.
7. **Content.** Home, installation, frameworks, AI agents, tokens, sizes and tones, theming, RTL
   and Arabic, page layout, notifications and dialogs, building a component (with its prompt),
   rules for agents.
8. **Remove the old showcase.** Delete the single-page app, its SSR entry and prerender script,
   and the tests that covered them; move `public/` under `pages/`.
9. **Housekeeping.** Update `_headers`, `robots.txt`, README and AGENTS.md; add
   `tests/showcaseSite.test.ts`; run `npm run check`; verify in the browser in light, dark, LTR and
   RTL, and at phone width.
